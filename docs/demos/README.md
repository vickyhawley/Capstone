# Demo recordings

Two kinds of demo live in this directory:

## [`final-submission.md`](final-submission.md) — capstone submission demo

Fifteen minutes, external audience (graders), solo presenter. Covers
everything shipped across all four sprints — live chat with four
behaviour beats, architecture tour, ADR walkthrough, evaluation
harness run, CI/CD tour, honest-gaps section. Includes a prep
checklist so nothing gets fumbled on the day.

This is the video the capstone submission PDF links to.

## [`sprint-1.md`](sprint-1.md) — Sprint 1 end-of-sprint record

Five minutes, internal audience (Product Owner = solo builder), per
the Handbook's "each sprint ends with a recorded demonstration"
requirement. Records the state at the end of Sprint 1 specifically —
corpus in, dataset written, retrieval running, baseline measured.

Later-sprint records (Sprint 2, 3, 4) were folded into the sprint-log
running commentary rather than separate demo videos, because the
Product Owner and the Scrum Master and the sole developer are all
the same person and a self-recorded weekly video wasn't producing
useful review signal beyond what the sprint log already captured.
Noted here rather than pretended around.
